## Running locally

No build tools needed — clone the repo and open `index.html` directly in a browser:

```bash
git clone https://github.com/Vishwashmaurya/vishwashmaurya.github.io.git
cd vishwashmaurya.github.io
open index.html   # or just double-click the file
```

## Deployment

This repo is named `vishwashmaurya.github.io`, so GitHub Pages serves it automatically from the `main` branch at the repo root. To update the live site, edit `index.html` and push to `main`:

```bash
git add index.html
git commit -m "Update portfolio"
git push origin main
```

Changes usually go live within a minute or two.
